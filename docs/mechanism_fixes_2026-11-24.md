## 1. 修复前的实测状态

在动代码之前，先测出基线（`config/diffusion.json`，720 步 consolidation）：

| 观测项 | 修复前实测 | 含义 |
|---|---|---|
| `\|g_u\|` | **0.0**（精确零） | U 永远学不到 |
| `\|g_v\|` | 7.0e-6 | V 只能以二阶速度爬 |
| `V_rms`（720 步后） | 0.00032 | 短通路实质恒等映射 |
| 块外耦合 `coupling` | 0.002478752176666359 → 0.0024790725693325496（**+0.013%**） | `W_blk` 几乎不生长 |

## 2. 六个机制缺陷与修复

### 2.1 短通路 U/V 双线性冷启动死锁

`shortcut_apply = z + silu(z @ U) @ V^T`，且 `V` 初值为**精确零**：

```
d(loss)/dU ∝ V = 0    ⇒ |g_u| 精确为 0（实测 0.0）
d(loss)/dV ∝ silu(z @ U)，而 |U| = 0.01 ⇒ |g_v| 仅 7.0e-6
```

U 被永久冻结，V 只能靠 `|U|=0.01` 这个微弱因子推动。

**修复**：`V` 改为小随机初值（仍近似恒等，因为 V 以乘性残差进入），`U` 尺度提到 0.5。

**实测效果**：

| | 修复前 | 修复后 |
|---|---|---|
| `\|g_u\|` | 0.0 | 2.0e-5 |
| `\|g_v\|` | 7.0e-6 | 8.2e-4（**117×**） |
| loss | 8.06984161569635 | 8.06981320392422（语义未变） |

### 2.2 门控监督在概率空间 → 梯度被 sigmoid 饱和压死

`b_rest = -5.5` 时 `sigmoid(-5.5) ≈ 0.004`，于是 `d(g)/d(logit) = g(1-g) ≈ 0.004`，
门控梯度比 logit 梯度弱约 **250 倍**。

**修复**：改为监督**激活前 logit**，且目标取执行阈值余量
`logit(theta_skip) + gate_margin`（= 1.49），而非 `logit(0.999) ≈ +7`
——门只需"够用"即可跳步，无需饱和到 1.0，且成熟斜坡从 `b_rest` 可达。

**实测**：`|g_bg|` 从 0.0202 提升到 0.74（37×）。

### 2.3 `init_iso` 过大导致 softmax 饱和，块外耦合梯度消失

`init_iso = 6.0` 让块间注意力 logit 差 6.0，softmax 后梯度极小。实测扫描：

| `init_iso` | `\|g_wblk\|` | 初始 coupling |
|---|---|---|
| 6.0 | 1.78e-5 | 0.0025 |
| 4.0 | 1.43e-4 | 0.0183 |
| **2.0** | **4.84e-4** | 0.1353 |
| 1.0 | 4.10e-4 | 0.3679 |
| 0.5 | 3.63e-4 | 0.6065 |

**修复**：取 `init_iso = 2.0`——梯度提升 **27×**，同时初始 coupling 0.135 仍保留
"块间弱耦合"语义（0.5 会让初始就强耦合）。

### 2.4 竞争门被无条件正则钉死在外部路径

原损失含 `lambda_ext_bias * pi_int.sum()`，**每步无条件**把 `pi_int` 往下压。
实测：内部路径明显更准（MSE 0.2895 vs 0.3615），`g_bcomp` 却是 **-0.0057**（负）。

更根本的问题是**两条分支的输入不对称**：内部路径从中间 ODE 态 `z_pre_final`
出发，外部专家吃原始观测 `x_obs`，"谁更准"的比较本身没有意义——实测在每个真实
语料窗口上 `advantage` 都是负的。

**修复**：
1. 竞争门改为**监督到误差更低的那一支**（logit 空间，`comp_gate_weight`）；
2. 比较时**两边用同一输入**（内部路径也从 `x_obs` 出发，与 `infer_system` 的推理
   语义一致）；
3. 目标取 `advantage` 的**符号**而非幅度（真实语料上 advantage 幅度小且噪声大，
   用幅度会让目标 logit 在窗口间翻转，净位移近零）；
4. 竞争门用独立的 `lambda_comp`，不再复用为跳步门设计的 `lambda_b`。

**实测**：`pi_int` 0.018 → **0.982**，`mode` 从 `external_fast` 变为 `internal_full`。

### 2.5 损失必须保持张量形态

Mora 的 autograd 只对**张量**输出播种根梯度
（`src/runtime/autograd.rs`：`grads[out_idx] = Some(vec![1.0])`）；
返回 float 会走 `zero_grads_for_leaves` 路径，所有叶子梯度归零。

`unified_diff_loss` 因此返回 1 元素张量，并让 `recon` 表达式里保留 `pi_int`
以维持到 `p_wcomp / p_bcomp` 的 autograd 边。

### 2.6 两处 API 误用

- `Tensor.item()` 在**可微上下文**返回张量，`float()` 不接受张量 → 改用 `to_list()`。
- `float(tensor)` 不是合法转换。

## 5. 必须诚实说明的负面结果

**短通路比满路径更准（0.1463 vs 0.2454），但这不证明短通路有效。**

对骨干单独测量 MSE 与 ODE 步数的关系：

| ODE 步数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| MSE | **0.0969** | 0.1207 | 0.1503 | 0.1802 | 0.2081 | 0.2334 | 0.2558 | 0.2755 |

观测基线 `MSE(x_obs, x_0) = 0.1180`。

即 **MSE 随步数单调恶化**，而 1 步（0.0969）优于观测基线。原因是
`backbone_ode_step` 做 `z + (x0h - z)/step_t` 的混合，`step_t=1` 时完全替换为
`x0h`，而多步会把同一个粗糙的 `x0h` 反复叠加（直接替换版 8 步更差：0.8822）。

**结论：当前骨干只在单步预测下准确，多步 ODE 必然退化。** 因此"NFE 8→2"
目前**不构成内化短通路有效的证据**——减少 NFE 有利是因为多步本身有害。

短通路的实际修正量也偏小：`|delta| rms = 0.0328` 对 `|z| rms = 0.331`
（约 10% 相对修正），`V_rms = 0.0089`。

块外耦合 720 步只长 0.206%，远小于文档暗示的量级。

### 待解决的下一个问题

骨干的多步退化是**架构级**问题（连续扩散主干的多步离散化），不是超参问题。
可行的方向：
1. 把 `backbone_ode_step` 换成真正的 flow-matching / DDIM 离散化，
   让 `x0h` 随 t 变化而非固定；
2. 或让骨干在多步下被显式训练（当前 `pretrain_backbone` 只训单步 x0 预测）；
3. 或重定义 NFE 指标——在当前骨干下，"NFE 越少越准"，8→2 的卖点本身需要
   重新论证。

## 7. 第二轮：真正的离散化改造（2026-11-24 下午）

第一轮修的是"机制是否在动"；这一轮修的是**离散化本身不是扩散过程**。

### 7.1 问题诊断

原实现的前向过程与采样更新**互不为逆**：

```
训练:  z_t = (1 - tau) * x_0 + tau * (x_obs + 0.25 * eps)
采样:  z   <- z + (x0_pred - z) / step_t
```

`x_obs` 混在噪声项里使前向过程非标准；采样更新式的系数 `1/step_t` 与噪声调度无关。

**决定性测量**：

| 测量 | 结果 | 含义 |
|---|---|---|
| 训练分布上 x0 预测误差（tau 1.0 → 0.125） | 0.1138 → 0.0545 | 模型**是**可用的 x0 预测器 |
| 采样轨迹上 x0 预测误差（tau 1.0 → 0.125） | 0.0935 → **0.2755** | 状态离开训练流形，误差累积 |
| 把采样器换成教科书 DDIM（权重不变） | 1.16 → 0.56（观测基线 0.118） | 比不做还差 → **采样器救不了训练错的骨干** |

### 7.2 改造内容

- 新增 `src/diffusion/schedule.mora`：标准 VP 调度（线性 beta）与 DDIM 更新（$x_0$ 参数化，支持 $\eta$ 随机项）。
- 骨干前向过程改为 $z_t = \sqrt{arlpha_t}x_0 + \sqrt{1-arlpha_t}\epsilon$。
- 观测改为**独立投影加性条件注入**（不用拼接：`Tensor::cat` 无 autograd 支持，实测 loss 正确但梯度精确为 0）。
- 采样器改 DDIM；重写 `infer_system` 的循环（旧循环以 2 为步长递减并据此索引调度，在 DDIM 下会索引到 -1，sqrt 负数 → 满路径 **NaN**）；跳步段不再消耗骨干求值。
- 骨干预训练改在**真实语料窗口**上进行（原先骨干在合成正弦上预训练、系统却在真实文本上评估）。
- `W_blk` 初值改为 $-	ext{init\_iso}\cdot 0.5$（原先恰在 clamp 边界，"增强耦合"的梯度全被 clip 掉）。

### 7.3 顺带修掉的实现缺陷

| 缺陷 | 后果 |
|---|---|
| `pretrain_backbone` 里噪声张量 `eps` 遮蔽了 AdamW 的 epsilon `eps` | 优化器项把 `[4,16,32]` 广播进 `[32,32]` 参数更新 → 形状错误 |
| AdamW `while` 循环体首句缩进与 `while` 同级 | 循环体边界错乱 |
| `float(tensor)`、`float(sys.bg_all[seg])` | Mora 的 `float()` 不接受张量；标量改用 `to_list()` |
| `no_grad` 块内的 `let` 是块局部的 | 块外引用被当成"非内置对象的方法" |
| `math.max` 不存在于 Mora 的 math 模块 | 运行时错误 |
| `assign x = expr(...)` 表达式外多一层括号 | 解析错误 |

### 7.4 结果对照（720 步，2 MB TinyStories，留出真实语料窗口）

| 指标 | 第一轮后 | 离散化改造后 |
|---|---|---|
| 满路径 MSE | 0.2454 | **0.0458** |
| 短通路 MSE | 0.1463 | **0.0528** |
| 观测基线 MSE | 0.1180 | 0.1046 |
| 骨干 NFE（满路径） | 8 | 9（8 步 DDIM + 1 终步） |
| 跳段数 | 3 | **5** |
| 跳步精度代价 | −40.4%（异常） | +15.3%（诚实） |
| `val_mse` | 0.2454 | **0.0477** |

**匹配计算量对照**（12 个留出窗口）——这才是主张能否成立的关键：

| 骨干求值次数 | DDIM MSE |
|---|---|
| 1 | 0.0472 |
| 8 | 0.0501 |
| **短通路：1 次求值，跳 5 段** | **0.0528** |

短通路用 **1 次**骨干求值达到 MSE 0.0528，而 DDIM 要用 **8 次**才到 0.0501 —— **约 8 倍的计算节省，精度相差 5%**。这是"内化短通路"第一次有意义的实证。

### 7.5 必须诚实说明的负面结果

**多步 DDIM 并不优于单步**：DDIM 用 1 次求值得 0.0472，用 8 次反而得 0.0501（越差）。已用 `obs_weight` 扫描（0.5 / 0.75 / 1.0 / 1.25 / 1.5）排除"投影权重"这一解释——五个权重下 MSE 都随步数单调上升。

结构性原因：DDIM 的 $\epsilon_	heta$ 通道把 $x_0$ 预测误差重新注回 $z$；本模型的条件极强（观测几乎决定答案），预测有偏，多步只会累积误差。**因此"NFE 8→2"这个卖点在当前骨干下的正确形式是"计算效率"而非"精度"**：1 次求值 ≈ 8 次求值的精度。

同时，块外耦合在本数据上**朝更强隔离方向微动**（0.36788 → 0.36726）。耦合现在是可学的了（不再被 clamp 卡死），方向由数据决定，而不是永远不动。

### 7.6 下一步

1. **起点噪声与步数预算匹配**：当前 `infer_start_step` 固定为 8。多步劣于单步的根因之一是观测投影到高噪声层时丢失信息，应让起点随可用步数自适应。
2. **骨干需要更强的 $\tau$ 依赖性**：当前 $x_0$ 预测误差随 tau 从 0.0550 降到 0.0385（动态范围 30%），但 DDIM 链上每步误差几乎不变（0.0642 → 0.0615），说明 DDIM 没能把"低噪声端更准"的优势传递下去。
3. **外部专家质量**：Mini-LLaMA 专家只在玩具语料上预训练过，文本解码输出为乱码；这限制了统一文本通路的上限。
